# Chroma Presets

Home Assistant custom integration for applying color/brightness presets to lights.

## Installation (HACS)

1. HACS → Integrations → ⋮ → Custom repositories
2. Add this repository URL, category `Integration`
3. Install "Chroma Presets" and restart Home Assistant

## Usage

Use the `chroma_presets.apply_preset` service to apply a preset to one or more light targets.
